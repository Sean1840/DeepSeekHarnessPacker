# 快速开始（用户）

开箱即用的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`@deepseek-ai/dsh`）绿色便携包。**无需安装 Node.js、无需命令行、无需联网也能用**。所有数据只保存在本文件夹内，**删除整个文件夹即彻底卸载**。

## 第一次用

1. 解压压缩包到任意目录（建议路径不含中文和空格）。
2. 双击 **`start.cmd`**。
3. 浏览器会打开 `http://127.0.0.1:20000`（首选端口；被占用会在 20000–21000 内自动换一个）。在页面「设置 → 模型」中填入 **DeepSeek API Key**。

启动窗口保持打开即表示服务在跑；按 `Ctrl+C` 或关掉窗口即停止。

## 三个入口

| 文件 | 作用 |
| --- | --- |
| `start.cmd` | 启动 Web UI（可按配置检查 dsh 内核，不升级便携包） |
| `update.cmd` | **整体升级**本项目便携包（在线下载或本地 zip） |
| `install.cmd` | 安装 / 修复（`node_modules` 损坏时联网重装） |

## 卸载

直接删除整个文件夹即可。不写注册表、不写系统目录、不写用户家目录。

数据（凭证、会话、插件）都在 `home` 文件夹。删掉 `home` = 恢复出厂设置，程序还在。

返回 [README](../README.md)。
